# Data Note

## Landsat Satellite Data

Source: USGS EarthExplorer

Source link: https://earthexplorer.usgs.gov/

Dataset: Landsat Satellite Imagery

Study area: Old Oyo National Park, Nigeria

Data type: Raster

Purpose: The Landsat imagery will be used to analyse land use and land cover changes around Old Oyo National Park and assess potential anthropogenic pressure on the park.

Time period: 2010–2025

Geometry type: Raster

Number of features: Not applicable because this is raster data. The data is represented as a grid of pixels.

Key information: The important information in the dataset includes the satellite acquisition date, spectral bands, pixel size, coordinate reference system and raster values.

Missing values or gaps: No missing values after the imagery is opened in QGIS.

Software used: QGIS

Data status: Downloaded from the USGS EarthExplorer and opened in QGIS for inspection.

## Population Data

Source: WorldPop

Source link: https://hub.worldpop.org/

Dataset: WorldPop Population Data

Study area: Old Oyo National Park and surrounding areas, Nigeria

Data type: Raster

Geometry type: Raster grid

Purpose: The population data will be used to examine population distribution around Old Oyo National Park and identify areas with higher concentrations of people that may experience greater potential anthropogenic pressure.

Number of features: Not applicable because this is raster data. The population is represented as values in raster cells.

Key information: The important information includes population values, pixel size, coordinate reference system, spatial extent and NoData values.

Missing values or gaps: [No missing data after opening the raster in QGIS]

Software used: QGIS

Data status: Downloaded from WorldPop and opened in QGIS for inspection.
